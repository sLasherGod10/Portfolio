## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn / pnpm

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```
